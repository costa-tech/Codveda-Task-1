# Modern Landing Page

A responsive, feature-rich landing page template with modern design elements and interactive components.

## Project Overview

This project provides a complete, production-ready landing page template built with HTML, CSS, and JavaScript. It features a clean, modern design with responsive components that work seamlessly across desktop and mobile devices.

## Features

- **Responsive Design**: Fully mobile-responsive layout that adapts to all screen sizes
- **Modern UI Elements**: Clean and contemporary design aesthetics
- **Interactive Components**: 
  - Mobile navigation menu
  - Smooth scrolling
  - Image lightbox gallery
  - Form validation
  - Entrance animations
  - Sticky navigation bar
- **Performance Optimized**: Image lazy loading and efficient animations
- **Cross-Browser Compatible**: Works on all modern browsers

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic knowledge of HTML, CSS, and JavaScript for customization

### Installation

1. Clone this repository or download the ZIP file
2. Extract the files to your desired location
3. Open `index.html` in your browser to view the landing page

```bash
# Clone the repository
git clone https://github.com/yourusername/Codveda-Task-1.git

# Navigate to the project directory
cd Codveda-Task-1
```

## Usage

The landing page is ready to use out of the box. You can customize it by:

1. Editing the HTML content in `index.html`
2. Modifying styles in `styles.css`
3. Extending functionality in `script.js`

### Customization Options

- Change colors by editing CSS variables in the `:root` selector
- Replace images with your own content
- Update text and links
- Add or remove sections as needed

## Project Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design rules
- `script.js` - Interactive features and animations
